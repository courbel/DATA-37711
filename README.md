# DATA-37711
Foundations of ML and AI course

## Structure

Each homework lives in its own folder (`homework_1`, `homework_2`, etc.). Each folder's `README.md` explains how to run its code.

## Homeworks

- [Homework 1](homework_1/): decision theory, proper scoring rules, SGD step sizes, residual normality tests, custom losses in JAX.
- [Homework 2](homework_2/): MLP with predicted uncertainty (taxi trips), encodings for high-cardinality categorical features (target encoding vs embeddings), Random Kitchen Sinks vs a one-hidden-layer MLP.
- [Homework 3](homework_3/): Poisson gradient boosting, a generalization bound for hyperparameter selection on a test set, train/validation/test grid search (KNN and random forest) on white wine quality, and boosting's generalization as trees are added.
